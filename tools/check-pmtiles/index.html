Remediation Snippets

If CORS or byte-range checks failed, configure your storage provider:

Cloudflare R2 / AWS S3 CORS Policy: 
[
  {
    "AllowedOrigins": ["*"],
    "AllowedMethods": ["GET", "HEAD"],
    "AllowedHeaders": ["Range", "*"],
    "ExposeHeaders": ["Content-Range", "Accept-Ranges", "Content-Length"],
    "MaxAgeSeconds": 86400
  }
]
Nginx Configuration: 
add_header Accept-Ranges bytes;
add_header Access-Control-Allow-Origin *;
add_header Access-Control-Allow-Headers "Range, Origin, Content-Type";
add_header Access-Control-Expose-Headers "Content-Range, Content-Length, Accept-Ranges";
